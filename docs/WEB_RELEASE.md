# TravelAgent Web 交付说明

日期：2026-10-29。本次冻结 Web 首版范围，集中验证已有功能，不以移动端、复杂多 Agent 或高级 Memory 作为发布前提。源码公开与公网服务部署分别验收；仓库可见性以 GitHub 实际设置为准。

## 使用范围

- Vue3 PC 工作台支持结构化规划、可选自然语言草案、执行状态、地图与多日时间轴、地点查询、调整重算、预算缺项和已保存版本。
- 真实地点与步行/驾车道路由统一高德 Provider 提供，direct 与可选 MCP 复用同一后端和算法。未知价格、营业与预约信息保持缺项，不使用模拟业务数据补齐。
- 支持逐日时段/停留/起终点、交通上限、有限备选地点比较、用户确认与来源记录，以及刷新/断线恢复。
- 账号模式提供个人数据隔离；部署范围为单 API 实例。原 Flutter 保留，apps/mobile 为后续接入说明。

安装及首次规划按 [使用手册](USER_GUIDE.md)；依赖与可选模型/MCP 配置按 [README](../README.md)。使用者自行配置授权，不提供公共 API Key 或共享账号。结构化表单不依赖模型，未配置模型不妨碍按表单规划。

## 固定验收范围

本地完整验收组为 `public-release-20261029`，以最终报告判定通过，历史报告不替代当前源码。完整流程复现见 [发布候选综合验收](architecture/LOCAL_RELEASE_CANDIDATE.md)，仓库安装与自动检查入口见 [验收记录](ACCEPTANCE.md)。

本组已通过 Python **335** 项、TypeScript **95** 项、Chromium/Firefox/WebKit 各 **103** 项（local 61、auth 16、resilience 26），共 **739 次**执行，零跳过和自动重试。类型/生产构建、Schema 一致性及本地 HTTPS **29** 项通过；九份浏览器报告的服务退出、清理和源码绑定均通过。

从干净源码快照新建 Python 环境安装锁定的 HelloAgents/MCP 依赖，pip check 通过；独立目录 npm ci、类型检查和生产构建通过，安装时 npm 审计报告零已知漏洞。此结果针对本机 Windows 环境，不冒充 GitHub Linux CI。新环境还用于最终归档的独立启动核验；最终 ZIP 的 4 项启动、97 项恢复/回退与候选汇总报告须在打包后生成，按确切归档 SHA 关联，不能使用旧归档报告替代。

## 已知使用边界

- 自然语言整理须人工核对。最近相对日期样本仍有模型漏填，日期候选供用户显式选用并保存，来源为用户填写；校验失败时保留原文和手动表单，不伪造成功草案。
- 交通是查询时点的道路事实，非未来出发时的保证。预约、实时票价、库存及未来营业时间须另行核实；餐饮和等候不自动计入。
- 本地验收不等于公网验收。服务器具备后，按 [部署说明](architecture/DEPLOYMENT.md) 核对域名/HTTPS、地图授权、账号、进程重启与外部备份，再开放在线服务。
- 本次没有移动端真机或正式服务器验收。详细历史失败与各项能力边界保留在架构记录中，不将定向测试或旧归档计作本版完整验收。

## 公开内容与下载

GitHub 只上传受控源码、锁文件、空配置示例、测试和说明。发布 ZIP 包含源码与生产 Web；安装依赖后仍需自行配置授权。环境文件、签名私钥、用户记录、数据库、日志、旧 POI 导出、缓存与本机验证产物排除在外。

发布 ZIP 的校验清单用于核对字节，不是数字签名。下载后执行 `python scripts/package_release.py verify <ZIP路径>`；可使用归档启动检查验证空库与账号边界。源码来源和第三方权利说明见 [NOTICE](../NOTICE.md)，本轮不新增开源许可证或改写原作者标识。

公网部署、移动客户端和进一步推荐质量改善作为独立后续里程碑，不重复扩充本次冻结范围。

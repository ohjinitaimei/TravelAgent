# 行程实用性人工复核表

本表用于真实使用者反馈，不以接口成功、评分高低或词面命中代替主观评价。没有真实反馈时填写“未评估”，不得生成模拟评论或满意度。

| 项目 | 实际记录 |
| --- | --- |
| 场景 ID / 行程版本 / 实际核对日期 | 待填写 |
| 城市、主题、交通方式、天数与站数 | 待填写 |
| 用户明确的时段、起终点、停留与交通限制 | 待填写 |
| 基线与采用方案是否来自同任务事实 | 待核对 |
| 原/采用总交通、最长段、最忙日分钟 | 待核对 |
| 移出/加入地点、真实评分及缺失项 | 待核对 |
| 主题是否符合实际需求，哪些站不合适 | 未评估 |
| 交通负担能否接受，哪一段需要调整 | 未评估 |
| 是否愿意按此计划出行，原因是什么 | 未评估 |
| 还缺营业/预约/费用等哪些信息 | 待核对 |
| 用户原话（取得同意后记录） | 未收集 |
| 结论：接受 / 需要调整 / 信息不足 / 未评估 | 未评估 |

请分别记录客观来源/约束检查与主观反馈。未来营业、预约和费用没有可靠来源时保留未知。个人行程与真实用户记录只存有权访问的本地业务记录，不随公开源码分发。

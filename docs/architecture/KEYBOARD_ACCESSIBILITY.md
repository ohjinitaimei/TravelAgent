# 键盘操作与表单错误定位

日期：2026-10-20。本轮仅调整 Web 交互，保留原有 API、账号隔离、编辑草稿与后端推荐/路线/调度实现；没有升级依赖。

## 操作方式

- 页面首个键盘入口为“跳到主要内容”。导航按钮提供明确名称与当前页面状态；切换页面后焦点落在新页面标题，窄屏隐藏文字时仍保留名称。
- 规划、登录、搜索、需求整理、草案补充与行程编辑采用同一表单组件。无效提交显示中文错误摘要并聚焦摘要；每个错误按钮可定位字段，字段通过 `aria-invalid` 与 `aria-describedby` 关联错误。修正、移除字段或重新应用值后更新错误状态。
- 检查必填、纯空格、数值范围与整数要求；每日结束须晚于开始。费用与预算允许小数，未知费用保留空白。草案未选择保存的字段不因未提交的输入而阻止其他补充。
- 编辑时可定位其他日期的错误；点击错误会切换日期并展开被折叠的约束区。所有日期均参与表单检查，不把隐藏日期中的空白停留替换为默认值。
- 日内上移/下移后，焦点回到该站定位按钮；跨日移动切换至目标日并聚焦该站；移除后聚焦相邻站点，空日回到标题。动作按钮不会误提交编辑表单。
- 地点详情和放弃修改使用原生模态对话框。打开后焦点进入对话框，Tab/Shift+Tab 在可用控件间循环，Escape 关闭或继续编辑，关闭后返回原按钮。详情可通过关闭按钮或点击遮罩关闭；异步返回时核对页面上下文，避免在其他页面打开过时详情。
- 保留输入、摘要、按钮与折叠区的可见焦点，响应系统减少 CSS 动效的偏好。地图仍提供原有可操作地点列表，SDK 不可用时不影响列表和时间轴。

## 实现与边界

`AccessibleForm.vue` 复用浏览器控件有效性及既有字段限制，只负责提交前提示和焦点定位。服务端 Pydantic 仍是权威校验；错误摘要不替代授权、业务配额、时间调度或路线计算。恢复草稿仍需用户保存，不因检查而自动提交。

`PoiDialog.vue` 管理详情展示、来源说明和原焦点。`dialogFocus.ts` 为两个对话框补充 Tab 边界处理，避免原生焦点顺序在边界进入浏览器工具栏。`RequestAssistant.vue` 保留用户选择哪些字段保存的规则。

Windows WebKit 会将声明为 date/time 的控件报告为 text，表单据声明类型补充日期和分钟格式检查；覆盖不存在的日期及含秒时间。秒数场景显式设置原生控件值并触发输入事件，其余主要交互使用真实键盘或鼠标事件，不把该格式注入宣称为真机时间选择器验收。隔离测试服务将单用户任务窗口额度设为 100，避免整套页面场景互相耗尽默认 20 次额度；生产设置保持不变，真实配额拒绝仍由后端 HTTP 检查覆盖。

本轮自动检查验证 DOM 名称、角色、描述关联、真实键盘事件和焦点，没有对 NVDA、VoiceOver 实际朗读、完整 WCAG 合规、Safari 真机或高德 SDK 内部控件作认证。此前真实地图记录保持其原验证范围；本轮使用显式 TEST ONLY 隔离服务，未消耗真实地图或模型配额。

## 复现

按 [ACCEPTANCE.md](../ACCEPTANCE.md) 执行完整仓库与浏览器检查。新增五个本地工作台场景覆盖跳转/导航、规划与搜索错误、隐藏日期/折叠约束定位、站点动作/放弃确认、地点详情；账号场景增加无效登录不发请求。三引擎均验证 Enter、Space、Tab、Shift+Tab 和 Escape 的相应操作，不用鼠标点击代替被验证的键盘操作。

# 推荐质量观察与多城实测

日期：2026-10-22。本轮扩展离线报告和授权真实数据样本，不修改生产推荐算法、Web、API Schema、数据库或依赖。报告中的通过仍仅指来源、契约和调度校验，不能代表用户满意度。

## 新增观察项

`scripts/verify_live_quality.py` 在既有拒绝门槛全部通过后，从已保存事实生成 `quality_observations`：

| 字段 | 定义与边界 |
| --- | --- |
| `days[].scheduled_minutes` | 当日用户设定停留 + 已保存站间交通 |
| `days[].travel_share_of_scheduled` | 站间交通 / 已排总分钟，保留四位小数；不是当天全部可用时间的占比 |
| `days[].remaining_minutes` | 每日时段减上述已排分钟；未扣起终点往返、未计入停留的餐饮及预约等待，不能当作已确认空闲时间 |
| `days[].longest_leg_minutes` | 当日已保存路段的最大耗时；没有路段时为 `null`，不虚构 0 分钟路段 |
| `days[].legs` | 路段起止 POI ID/名称、模式、耗时、距离和原获取来源；不复制大体积折线 |
| `day_load_spread_minutes` | 最忙一天与最轻一天已排总分钟之差；单日为 0，不表示推荐满意 |
| `attention` | 当天交通不少于停留时列出 `travel_at_least_stay` 与日序号，仅提示复核，不拒绝可行行程、不改变算法 |

报告明确 `origin_return_included=false`、`future_opening_verified=false` 和 `subjective_satisfaction=not_assessed`。顶层单列 `subjective_quality_assessment=not_assessed`、`travel_attention_case_count`。既有 `review_required` 合并字面/城市线索与交通提示；没有提示也不能当作人工评审完成。`passed` 和失败计数语义保持原样。

这些计算只汇总事实，没有查询新路线或开发第二套排序/调度算法，也没有把 LLM 用作评分裁判。缺失费用、营业和人均消费等继续保留缺失状态。

## 本轮真实结果

授权高德、出发日 2026-10-23、每站停留 30 分钟、09:00–22:00。三个真实任务均成功并通过来源/调度校验；失败、状态未知和验收拒绝均为 0，服务优雅退出。未调用模型或加载地图 SDK，运行库独立于个人数据。

| 场景 | 站间交通 / 距离 | 每天已排总分钟 | 最长路段 | 交通占已排时间 | 单次耗时 |
| --- | --- | --- | --- | --- | --- |
| 杭州 6 站 | 279 分 / 20.733 km | 290、169 | 160、67 分 | 68.97%、46.75% | 10.61 秒 |
| 北京 3 站 | 33 分 / 7.089 km | 123 | 17 分 | 26.83% | 6.56 秒 |
| 成都 4 站 | 21 分 / 1.385 km | 141 | 13 分 | 14.89% | 10.58 秒 |

耗时为单次本机/网络样本，不构成服务时限承诺或传输性能比较。杭州两天负担相差 121 分钟；现有有限地理候选返回 `no_geographic_change`，本轮没有修改算法或声称改善了交通。

复核发现：

- 杭州首日 200 分钟步行交通、90 分钟停留，触发交通提示；最长一段 160 分钟。时段可行不能说明该步行负担适合用户。应先收集最长可接受步行/交通偏好，再增加相应约束；不能替用户假定统一阈值。
- 杭州记录中有两个不同 ID 使用相同显示名称。它们仍是不同真实记录，是否同一地点、入口或不同位置须核对坐标及来源；不能仅凭名称自动合并。
- 成都关键词的名称/分类字面命中 3/4，另一个高德搜索结果标为购物相关分类。保留 POI 证据供核对；字面未命中不自动等于语义不相关，名称/分类命中也不等于满意度。
- 北京名称/分类字面命中 3/3，杭州 6/6；这不能覆盖预约、实际游览价值或出行日营业。杭州 6 个与北京 3 个地点缺人均消费，北京 2 个缺营业时间。成都样本可选字段有值也不验证未来营业；三个行程完整预算均为未知。

本机报告：`artifacts/diverse-quality/2026-10-22/report.json`，原始证据不进入 Git/发布包。复跑可能返回不同事实或明确失败；没有固定 POI 名称的生产断言，也没有测试结果回灌生产。

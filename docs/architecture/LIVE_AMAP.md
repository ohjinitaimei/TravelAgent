## 验证范围

| 链路 | 结果 |
| --- | --- |
| `/pois` 搜索杭州真实地点、`/pois/{id}` 读取详情 | 直接 Provider 和 MCP 均通过，来源为 amap |
| `/routes` | 直接 Provider 步行、驾车均通过；MCP 步行通过；返回真实距离、时长及折线 |
| 异步创建规划任务、状态和事件 | 直接 Provider 两天四站、MCP 一天两站成功；复用现有排序与时间调度 |

| 行程调整 | 两天行程反转每日顺序、修改停留时长后重算成功；新版本关联原行程，原记录不变 |
| 已保存行程 | 列表包含原版和调整版，均可重新读取 |
| Web | Chromium 通过 Vite 代理读取真实保存行程，时间轴展示真实地点；刷新恢复与预算未知提示复查通过 |
| 数据完整性 | POI/交通保留来源，真实路线有几何点，时间落在用户指定时段；费用未知不补零或虚构总额 |

真实路线样本的查询时结果：同一对真实 POI 步行 3.960 km、53 分钟，驾车 4.859 km、24 分钟。该样本仅验证两种接口返回及标准化，不代表其他城市、未来出发时间、最优路线或完整出行费用。

未启用模型调用、FixtureProvider 或测试业务数据。全部地点与交通来自授权高德，日期、停留时长和每日时段是此次验收输入。此次选择杭州为联调样本，不代表用户的实际旅行计划。
